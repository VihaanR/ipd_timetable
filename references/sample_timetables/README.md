# Source timetable images

The three real DJSCE CSE-DS SY Sem IV timetables (Divisions D1, D2, D3) were shared inline in
chat as pasted images, not as files on disk, so the original image files could not be copied into
this folder. They were transcribed directly from visual inspection into
[`data/reference/djsce_cse_ds_sy_sem4.json`](../../data/reference/djsce_cse_ds_sy_sem4.json).

If you have the original image files, drop them here as `D1.jpg`, `D2.jpg`, `D3.jpg` for
traceability.
